# Architecture Decision Records (ADR)

Ghi lại các quyết định kỹ thuật quan trọng và lý do chọn phương án.

## Danh sách
Chưa có quyết định được xác nhận. Tạo file `ADR-0001-short-title.md` cho quyết định đầu tiên.

## Mẫu ADR

```markdown
# ADR-XXXX: [Tiêu đề]

- Status: Proposed | Accepted | Superseded
- Date: YYYY-MM-DD
- Decision owners: [Vai trò/người phụ trách]

## Context
Vấn đề và các ràng buộc.

## Options considered
Các phương án và ưu/nhược điểm.

## Decision
Phương án được chọn.

## Consequences
Tác động, đánh đổi và công việc tiếp theo.
```
