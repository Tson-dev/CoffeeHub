## Quy ước
- Ghi rõ trạng thái: `Draft`, `Reviewed`, hoặc `Approved`.
- Không mô tả một chức năng là đã triển khai nếu chưa kiểm tra source code.
- Sơ đồ Mermaid nên được lưu dưới dạng mã nguồn trong Markdown để dễ review bằng Git.
- Khi tài liệu thay đổi đáng kể, cập nhật ngày và người rà soát.
